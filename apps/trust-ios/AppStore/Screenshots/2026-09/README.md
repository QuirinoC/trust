# Trust App Store screenshot source — September 2026

This historical set contains the six annotated panels prepared for the App Store listing. On 2026-09-30, App Store Connect showed six ordered screenshots in each of the iPhone 6.9-inch, iPhone 6.5-inch, and iPad 13-inch groups. The live 6.5-inch map image was visually compared with the local asset and matched. The later dated proposal is in [`../2026-10/`](../2026-10/README.md); both sets predate subsequent UI changes and are not current design guidance. Changing local files does not update App Store Connect.

## Upload assets

- `iphone-69/`: six annotated 6.9-inch iPhone panels at **1320 × 2868**, RGB PNG.
- `iphone-65/`: the same six panels at **1242 × 2688**, RGB PNG for the 6.5-inch listing group.
- `ipad-13/`: the same six panels at **2064 × 2752**, RGB PNG for the 13-inch iPad listing.
- `raw/`: local-only direct simulator captures used as the screen layer. These are reproducible and ignored by Git; do not upload the unannotated source images.

The app UI was captured from the September source with the DEBUG-only, offline screenshot fixture. Names and locations are synthetic. The live-location panel uses a Plus-enabled synthetic viewer so its live pin and map entitlement count agree; other panels retain the Free viewer. The phone-search panel uses the fictional North American test number `+1 (202) 555-0134`; the result represents a verified account that opted into discovery. No real user account or location is included.

## Historical record

Do not regenerate this set or reuse it as a screen specification. Follow the [screenshot workflow](../README.md) for fresh captures and [DESIGN.md](../../../../../docs/DESIGN.md) for the current direction. The historical panels use Trust’s porcelain, navy, blue, and teal palette with one headline, one short explanation, and a captured September app screen.
