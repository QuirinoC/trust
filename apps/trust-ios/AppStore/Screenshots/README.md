# App Store screenshots

The current composed set is in [`2026-10-25/`](2026-10-25/README.md). Astra passed the raw captures and all 18 final panels; they are uploaded and verified in the three App Store Connect groups with six complete images each. The 25 October set supersedes the historical [`2026-10/`](2026-10/README.md) set captured on 5 October, which predates current Sharing and Map changes. [DESIGN.md](../../../../docs/DESIGN.md) defines the current screen direction. The new captures use the DEBUG-only fictional demo fixture and do not prove production behavior or real account/location data. The screenshot README and durable release evidence record the image checksums, ordering, and prior-image backup.

See the dated set README for the exact source, simulator, capture, composition, and manifest provenance. To create a new dated set, use [`../capture-app-store-screenshots.sh`](../capture-app-store-screenshots.sh) with a new `OUTPUT_ROOT`, then run the builder against those fresh raw captures; do not rebuild from stale ignored `raw/` files. The script builds from source, creates and removes one simulator at a time, and does not upload anything. Set `TRUST_ALLOW_PARALLEL_SIMULATORS=1` only when another booted simulator should stay untouched. See [review readiness](../REVIEW-READINESS.md) for submission checks.
