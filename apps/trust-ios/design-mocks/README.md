# Archived HTML design prototypes

These standalone HTML prototypes are retained as historical artifacts. They are not current product specifications and must not guide implementation. Use [docs/DESIGN.md](../../../docs/DESIGN.md) for current visual direction and screen intent.

To inspect a prototype, open `index.html` in a browser or run `python3 -m http.server 8765` from this directory. The HTML, CSS, and JavaScript here are not authoritative for the app.
